# homebrew-tools

Homebrew tap for CLI tools by [xronocode](https://github.com/xronocode).

## Setup

```bash
brew tap xronocode/tools
```

## Available formulae

| Formula | Description | Repo |
|---------|-------------|------|
| `pdf-kompakt` | Interactive PDF compression tool | [xronocode/kompakt](https://github.com/xronocode/kompakt) |

## Install

```bash
brew install xronocode/tools/pdf-kompakt
```

Or after tapping:

```bash
brew tap xronocode/tools
brew install pdf-kompakt
```

## Update

```bash
brew update
brew upgrade pdf-kompakt
```
